# Brand — Portfolio V4

_Status: existing UI preserved; redesign deferred_

This document records the current UI in `apps/web`. The hiring-oriented purpose is defined in [README](README.md); future architecture and implementation order are defined in [the architecture policy](docs/architecture.md). A new visual direction will be compared through generated concepts and specified before frontend implementation; repository organization does not change the typography or palette below.

## Typography

- Display and emphasized Japanese copy: Shippori Mincho, weight 500.
- Body, navigation, controls, metadata, and metrics: Zen Kaku Gothic New, weights 400, 500, and 700.
- Prose uses strict Japanese line breaking and phrase-aware wrapping. Manual line breaks are reserved for intentional display composition only.

## Palette

The existing dark, neutral product-cinema palette remains in place. A broader palette and voice pass is deferred until explicitly requested.
